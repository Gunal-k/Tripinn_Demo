# 🌴 Tripinn Holidays

> A modern travel platform for discovering and booking curated group tours and travel experiences.

**Tripinn Holidays** is a travel platform built to showcase curated tour packages, provide customers with essential trip information, and make it easy for travelers to connect with the Tripinn Holidays team for bookings and enquiries.

The project is designed with a production mindset, focusing on performance, responsive design, maintainability, and a smooth customer experience.

---

## ✨ Features

- 🏝️ Browse available tour packages
- 📋 Detailed tour information
- 📅 Trip dates and duration
- 💰 Package pricing
- 🏨 Accommodation and inclusions
- 🚐 Transportation details
- 📸 Travel-focused visual experience
- 📱 Fully responsive design
- 💬 WhatsApp-based booking/enquiry flow
- 📞 Direct customer enquiry options
- ⚡ Fast and lightweight frontend
- 🔍 SEO-friendly structure
- 🔐 Production-ready architecture

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/tripinn-holidays.git
```

### 2. Navigate to the project

```bash
cd tripinn-holidays
```

### 3. Run the project

Since the current version uses HTML, CSS and JavaScript, you can open `index.html` directly in a browser.

For development, using a local server is recommended.

For example, with VS Code:

```text
Right Click → Open with Live Server
```

## 📱 Booking Flow

The current website uses a simple customer enquiry flow:

```text
Customer
   ↓
Browse Tour
   ↓
View Package Details
   ↓
Click "Book Now"
   ↓
WhatsApp
   ↓
Tripinn Holidays Team
   ↓
Booking Confirmation
```

This keeps the booking process simple while the platform is being developed toward a more complete booking system.

## 📈 Product Vision

Tripinn Holidays aims to provide a simple and reliable way for travelers to discover group trips, understand exactly what each package includes, and connect with the travel team without unnecessary complexity.

The platform is being developed with scalability in mind so that new destinations, packages, booking functionality, and business operations can be added without rebuilding the entire system.
